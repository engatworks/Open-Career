# How Open Career works

Open Career combines ChatGPT research, the user's connected Gmail and an owner-private tracker. The public GitHub repository contains source code and documentation, not the private CV or outreach records. There is no added paid contact-data service. Existing ChatGPT access and provider limits still apply; this is not an unlimited free Apollo database.

1. **Load current instructions and evidence.** Retrieve the private Site, current candidate facts, exact CV fingerprint, settings, previous outreach and latest contract. Never rely on a scratch folder or old conversation as the candidate truth source. If newer user statements conflict with stored profile facts, reconcile them or omit the disputed claim before writing.
2. **Check the inbox and history.** Inspect actual Gmail threads and Sent for replies, bounces, declines, prior company contact and uncertain deliveries. Do not auto-reply or follow up. Respect suppression and one initial contact per company.
3. **Discover a varied employer pool.** Rotate official contractor/supplier directories, electrical exhibitions, professional communities and employer searches. Cover SMEs and large companies throughout Saudi Arabia. Research 10–15 deeply; a directory listing alone is not a completed review.
4. **Research the company.** Confirm its Saudi operation and official domain. Read relevant products, services or projects. Identify where supervised junior electrical/electronics experience could contribute. Separate facts from speculation.
5. **Research the person.** Prioritize engineering, operations, maintenance and project managers, then HR/recruiters. Founders/general managers remain eligible where relevant, especially smaller firms. A relevant professional referral contact can also be appropriate. Check namesakes, role changes and conflicting employment evidence. Require their exact published corporate email; never generate a pattern.
6. **Choose the intent.** A speculative paid-junior inquiry or referral request needs no advertised vacancy or application account. If applying to a specific opening, assess all mandatory requirements. Exclude internships, senior-only, Saudi-national-only or unmet-credential vacancies without excluding the entire company.
7. **Write and validate.** Save the company/person research record, actual queries, original sources, limitations and selection reason. Write a concise tailored inquiry using approved CV claims and their supervised scope. The queue re-fetches source quotations. A careers inbox is a documented fallback only after named-person searches and an explicit official CV invitation.
8. **Deliver once.** Confirm authenticated Gmail, current background CV verification, live delivery and the rolling 15-send cap. Reserve one message, forward the returned recipient/subject/MIME payload unchanged through native Gmail, and never use a different sender after a rejection or uncertain result.
9. **Verify and record.** Read back the actual Gmail message. Verify recipient, subject, the PDF filename/type, and SHA-256 of attachment bytes. Save actual Gmail message/thread IDs. A draft, queue item or schedule is not a delivery receipt; Gmail acceptance is not proof of inbox placement or a job opportunity.
10. **Report and continue.** Close the run with actual researched/queued/sent/held counts, named-person versus careers-inbox sends, reply findings and precise blockers. Held sources can be researched again; contacted companies are not contacted twice.

## Recovery

An ambiguous Gmail attempt remains quarantined and consumes quota; never automatically retry. If a later user-authorized run confirms that an old packet is still queued, was never reserved and has no matching Gmail message, it can cancel that unsent packet and rebuild it from fresh research. This does not permit recovery around a safety rejection. Old evidence must not be silently reused.

## User controls

The Research screen shows source directories, evidence and holds. Outreach shows queued/sent messages and provider receipts. Activity records events. Setup & settings contains the delivery switch, candidate evidence and CV upload. Manage the linked daily schedule in ChatGPT. Uploading a new CV invalidates its previous attachment verification until a new exact-byte test succeeds.

The tracker does not secretly send emails when a button is clicked: research and Gmail delivery run through connected ChatGPT. Keeping the laptop on is unnecessary. Provider outages, missing authorization, source blocks and low contact yield must be reported rather than hidden. Browser visual QA and recipient response rates are separate from API/build verification.
